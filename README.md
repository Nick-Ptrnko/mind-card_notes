Цей фрагмент коду виконує експорт усіх нотаток із бази даних у звичайний JSON-файл, перетворюючи об'єкти Python у зручний для читання текстовий формат.
1. Формування списку словників (data = [...] for note in notes)
```python
data = [
    {
        "id": note.id,
        "title": note.title,
        "content": note.content,
        "created_at": note.created_at.strftime("%Y-%m-%d %H:%M:%S")
        if note.created_at
        else None,
    }
    for note in notes
]
```
 * Це генератор списку (List Comprehension). Він проходить по кожному об'єкту note у списку notes і перетворює його зі складного об'єкта Python на звичайний словник (dict), який легко зберегти у форматі JSON.
 * Перетворення дати (strftime): Об'єкти типу datetime (дата і час створення) неможливо напряму записувати в JSON. Метод .strftime("%Y-%m-%d %H:%M:%S") перетворює дату на красивий рядок (наприклад, "2026-06-06 14:30:00").
 * Конструкція if note.created_at else None: Це перестраховка. Вона перевіряє, чи дійсно дата існує: якщо раптом поле порожнє, запишеться None, і програма не впаде з помилкою.
2. Безпечне відкриття файлу (with open(...) as f)
```python
with open(filename, "w", encoding="utf-8") as f:
```
 * Контекстний менеджер with відкриває файл із назвою filename у режимі запису ("w" від англ. write). Його головна перевага — він автоматично закриє файл після завершення запису, навіть якщо під час виконання виникне помилка.
 * encoding="utf-8": Це критично важливий параметр для роботи з українською мовою. Якщо його не вказати, під час запису кирилиці у файл можуть з'явитися «кракозябри» або виникнути помилки кодування.
3. Запис у файл
```python
(json.dump(...))
json.dump(data, f, ensure_ascii=False, indent=4)
```
Функція json.dump() бере підготовлений список словників data і записує його у відкритий файл f:
 * ensure_ascii=False: Дозволяє зберігати букви української (та інших не-англійських мов) алфавіту в їхньому звичному вигляді (наприклад, "Заголовок"), а не в зашифрованому форматі Unicode-ескейпів (наприклад, "\u0417\u0430...").
 * indent=4: Додає відступи у 4 пробіли для кожного рівня вкладеності. Без цього весь JSON записався б в один довгий рядок, а з відступами він стає «людино-читабельним» (pretty-print).
4. Повернення результату (return len(data))
```python
return len(data)
```
 * Метод підраховує загальну кількість елементів у списку data за допомогою len() і повертає це число. У файлі main.py ми використовуємо це число, щоб вивести користувачеві гарне повідомлення: «Успішно збережено 5 нотаток у файл».
