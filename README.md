## NoteRepository звернення до mySQL
​У проєктуванні програмного забезпечення класи виконують різні ролі. NoteRepository належить до класу-сервісів (або **Repository**).
​Його мета — **не зберігати дані всередині себе, а виконувати дії** (робити запити до бази даних).
- ​Коли ви викликаєте repo.get_all(), об'єкт repo не тримає список нотаток у своїй пам'яті.
- ​Він просто слугує «набором інструментів»: ви звертаєтесь до нього, він іде в базу даних, забирає звідти все необхідне, повертає вам результат і знову стає «порожнім».

​У програмуванні такі об'єкти, які не зберігають внутрішнього стану (тобто не мають змінних на кшталт self.X = ...), називають **stateless (без стану)**. Їм не потрібно нічого пам'ятати про себе між викликами методів.
Для контрасту порівняйте NoteRepository з класом Note:
```python
note = Note(note_id=1, title="Покупка", content="Купити молоко", created_at="...")
```
Цей об'єкт повний. Він створений спеціально для того, щоб зберігати стан (дані). У нього всередині чітко записані:
note.id = 1
note.title = "Покупка"
note.content = "Купити молоко"
Підсумок
Моделі даних (як Note) — створені, щоб зберігати дані (вони «повні»).
Репозиторії та сервіси (як NoteRepository) — створені, щоб виконувати дії (вони не зберігають стан, тому виглядають «порожніми», але це абсолютно нормальна і правильна архітектура).
### connection (Об'єкт з'єднання)
   * Методи connection.commit() та connection.close() застосовуються саме до об'єкта з'єднання. Це методи екземпляра (або методи об'єкта), оскільки ви викликаєте їх на конкретній створеній змінній connection, а не на самому класі pymysql.Connection. З'єднання відповідає за транзакції (commit) та відкриття/закриття каналу зв'язку з базою (close).
   * Змінна connection створюється всередині методу `_create_table() і` є локальною. Вона існує лише поки виконується цей метод. Відсутність префікса self.: Оскільки в коді написано просто connection = ..., а не self.connection = ..., Python не прив'язує цей об'єкт з'єднання до екземпляра репозиторію (self).
### cursor (Об'єкт курсору)
   * Методи cursor.execute(), cursor.fetchone(), а також cursor.fetchall() та cursor.lastrowid викликаються на об'єкті курсору.
   * Курсор — це ваш «виконавець» всередині цього з'єднання: він бере SQL-запит, надсилає його базі даних (execute), а потім витягує звідти результати (fetchone / fetchall).
